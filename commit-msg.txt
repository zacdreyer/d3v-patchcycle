Fix CI: guard-step syntax error, pip-audit precedence, container matrix

Root causes (all in CI plumbing, not product code):
- Guard step: bash syntax error from an unbalanced-quote regex -> exit 2 on
  every unit job before pytest ran. Replaced with tools/ci_guard.py (unit
  tested, self-exempt).
- Lint job: pip-audit step always exited 1 due to shell precedence
  (|| binds tighter than &&). Now just pip-audit --strict.
- Container jobs: (a) -k filter used image names containing colons, which
  pytest's -k expression parser rejects; test IDs now use colon/dot-free
  aliases matched by a matrix 'alias' field. (b) ubuntu:22.04 (py3.10) and
  EL9 (py3.9) ship Python below the >=3.11 floor, so pip install failed;
  per-image bootstrap installs python3.11 (deadsnakes for ubuntu:22.04,
  AppStream python3.11 for EL9).
- pip extras spec quoted against shell globbing.
- Verified locally: full non-container suite exit 0; -k ubuntu_22_04 selects
  exactly the right container test; all workflow YAML parses.
